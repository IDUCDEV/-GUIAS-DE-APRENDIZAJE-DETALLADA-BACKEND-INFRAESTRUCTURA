# Quick Reference - Referencia Rápida

Esta tarjeta contiene los atajos más utilizados para referencia rápida.

---

## Modos

| Tecla | Modo |
|------|-----|
| `Esc` | Normal |
| `i` | Insert |
| `v` | Visual |
| `V` | Visual Line |
| `:` | Command-Line |
| `Ctrl+v` | Visual Block |

---

## Navegación Básica

| Atajo | Función |
|-------|--------|
| `h` |← |
| `j` |↓ |
| `k` |↑ |
| `l` |→ |
| `w` | Word siguiente |
| `b` | Word anterior |
| `0` | Inicio línea |
| `$` | Fin línea |
| `gg` | Inicio archivo |
| `G` | Fin archivo |

## Atajos de Leader

| Atajo | Función |
|-------|--------|
| `<leader>` (espacio) | Leader key |

### Archivos

| Atajo | Función |
|-------|--------|
| `<leader>ff` | Buscar archivos |
| `<leader>fg` | Git files |
| `<leader>fe` | Explorer |
| `<leader>fr` | Recientes |
| `<leader>,` | Buffers |

### Búsqueda

| Atajo | Función |
|-------|--------|
| `<leader>sg` | Grep |
| `<leader>s/` | Grep cwd |
| `<leader>sc` | Command history |

### Git

| Atajo | Función |
|-------|--------|
| `<leader>gs` | Git status |
| `<leader>gl` | Git log |
| `<leader>gd` | Git diff |
| `<leader>gg` | LazyGit |

### Terminal

| Atajo | Función |
|-------|--------|
| `<leader>ft` | Terminal |
| `<leader>fT` | Terminal cwd |
