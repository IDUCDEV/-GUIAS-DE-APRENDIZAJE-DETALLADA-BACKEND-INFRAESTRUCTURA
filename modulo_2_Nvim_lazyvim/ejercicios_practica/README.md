## 🚀 Cómo usar este laboratorio

1. Abre tu terminal en esta carpeta.
2. Abre cualquier archivo con Neovim: `nvim <nombre_archivo.dart>`.
3. Sigue las instrucciones comentadas en cada archivo para realizar las tareas.
4. Recuerda: **¡no uses el ratón ni las flechas de dirección!**
